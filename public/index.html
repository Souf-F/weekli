Ton code de la semaine devient
tes posts LinkedIn.

PostForge connecte ton GitHub à ton compte Claude. Tu demandes « fais mes posts de la semaine », Claude lit tes commits et rédige, avec ton abonnement, sans clé API.

Ajouter à Claude

Comment ça marche

  1. Connecte

    Ajoute PostForge comme connecteur dans Claude et autorise la lecture de ton profil GitHub public.

  2. Demande

    Lance le prompt posts_semaine ou écris simplement « fais mes posts LinkedIn de la semaine ».

  3. Publie

    Claude analyse tes commits, choisit les meilleurs sujets et rédige. Tu relis, tu ajustes, tu publies.

Les outils exposés à Claude

activite_github

Tes commits récents, sans le bruit (merge, typo, chore).

details_repo

Description, site, langages et README d'un projet.

details_commit

Fichiers modifiés et extraits du diff, pour raconter un problème résolu.

capturer_site

Captures de tes démos, sur domaines vérifiés. Bientôt.

Sécurité

  • Lecture seule : scope GitHub read:user, uniquement tes repos publics.
  • Aucune clé IA stockée : c'est ton Claude qui rédige, PostForge ne fournit que les données.
  • OAuth 2.1 + PKCE avec protection CSRF et consentement explicite.
  • Rien n'est publié automatiquement : tu gardes toujours la main.

Ajouter PostForge à Claude

  1. Dans Claude, ouvre Paramètres → Connecteurs → Ajouter un connecteur personnalisé.
  2. Colle cette URL :
https://postforge.example/mcp

Connecte-toi avec GitHub quand Claude te le demande, c'est prêt.
